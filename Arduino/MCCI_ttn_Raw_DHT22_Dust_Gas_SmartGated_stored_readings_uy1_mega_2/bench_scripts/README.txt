Bench simulation scripts for automated verification of stored readings, night mode,
and command handling on ATmega2560 hardware testbeds.

  night_b1.sh    Night flow simulation on a BENCH-ADC build (store, mid-night reset, records, flush, critical floor)
  cmds_b1.sh     /@H, /@L, /@O, /@U serial downlink command checks
  commit2_b1.sh  Apply and commit battery profile verification
  flash12.sh     Batch flash utility for test boards in sequence
