# loraexperiments

LoRa and LoRaWAN sensor nodes, the Raspberry Pi gateway and the ThingsBoard
dashboard used in the deployment.

| Folder | Contents |
|---|---|
| `Arduino/` | Production node firmware and libraries. See `Arduino/README.md`. |
| `thingsboard/` | Public dashboard export and TTN payload formatters. See `thingsboard/README.md`. |
| `loragateway/` | Gateway installer zip. See `loragateway/README.md`. |
| `EUI_generator/` | Script that generates LoRaWAN EUIs. |
